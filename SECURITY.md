# Security Policy

## Supported Versions

Security updates are applied to the latest `main` branch and most recent tagged release.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report vulnerabilities privately through GitHub Security Advisories:

- Navigate to **Security -> Advisories -> Report a vulnerability** in this repository (`https://github.com/jelmervdm/spinq/security/advisories/new`).

Include:

- A clear description of the vulnerability and potential impact.
- Steps to reproduce or a minimal proof of concept.
- Any affected configuration or Python/container version details.

You can expect an initial acknowledgment within 7 days and coordinated disclosure once a fix is ready.
